pokerarena

A poker table you can actually sit at.

Repository Start Play with friends Who else is at the table The maths behind it

Deal, bet, show down — with friends in a browser, with bots in process, or both at the same table. Nothing to configure to get started: the built-in opponent needs no API key and no model download.

Start a table

git clone https://github.com/frla18cz/poker-arena
cd poker-arena
pip install -e '.[dev]'
poker-arena                      # open http://127.0.0.1:8771

Requires Python 3.14+.

Playing with other people

Seats are handed out as links. Open the table panel and every human seat has a URL and a QR code beside it — send one to each friend.

poker-arena --lan                                       # everyone on your Wi-Fi
poker-arena --public-base https://your-tunnel.example   # over the internet

A seat link is a chair at the table: whoever holds it plays that seat and sees its cards. There are no accounts and no passwords — the link is the credential, so share them the way you would hand someone a seat in your living room.

Who else is at the table

Seat kindWhat it is
humanwaits for a person to click
heuristicbuilt-in bot: pot odds against a rough read of its own hand. No key, no model.
solverMonte Carlo equity from pokersolver. No key either — it pays in time.
llma language model you point it at, with your own key

Anything else plugs in through the registry — the arena never needs to know what is behind a seat, only that it can decide:

from pokerarena.engine.seat_registry import register

register("my_bot", lambda build: MyStrategy())

That is also how a private bot joins a public table without shipping any of its code here.

Language-model seats

Bring your own key. The arena does not ship a model and does not proxy anyone’s traffic — one prompt per decision, straight from your machine to whatever provider you already pay for. To keep it local, run Ollama or LM Studio and point ARENA_LLM_API_BASE at it; then no key is needed and nothing leaves the machine.

What it is not

  • Not a poker site. No money, no accounts, no chips that mean anything.
  • Not a training tool — no hand database, no leak finding.
  • The built-in bot is deliberately simple and beatable. For a hard opponent, use a solver seat.
  • LLM seats are only as good as the model behind them. The arena gives a model a chair and a legal move list; it does not make it play well.
